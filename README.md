# جاده‌بازار

<p align="center"><img src="brand/logo.svg" alt="جاده‌بازار" height="90"></p>

سایت خرید و فروش لوازم جانبی خودرو: صوتی و تصویری، روکش و کفپوش، رینگ و لاستیک، دزدگیر، چراغ و ابزار امداد.

## امکانات
- جستجو، فیلتر بر اساس خودرو، دسته‌بندی و وضعیت (نو / کارکرده)، مرتب‌سازی بر اساس قیمت و تاریخ
- ثبت آگهی فروش با بررسی قیمت (تومان) و شماره موبایل
- نشان کردن آگهی‌ها و مدیریت «آگهی‌های من» (حذف، علامت فروخته شد)
- راست‌به‌چپ، مناسب موبایل، حالت روشن و تاریک

## یادداشت
این نسخه نمایشی است و سرور ندارد: آگهی‌های «نمونه» ساختگی‌اند و آگهی‌هایی که کاربر ثبت می‌کند فقط در `localStorage` همان مرورگر ذخیره می‌شوند. برای اشتراک آگهی‌ها بین کاربران باید یک بک‌اند (مثلاً Firebase) اضافه شود.

## اجرا
فقط `index.html` را در مرورگر باز کنید، یا با GitHub Pages منتشر کنید (Settings → Pages → Branch: `main`, folder: `/ (root)`).
